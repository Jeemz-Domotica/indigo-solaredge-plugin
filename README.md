# indigo-solaredge-plugin
## Installation:
1. Download and install Indigo
2. Download the .zip of this repository (green 'code' button)
3. Extract the 'velux-indigo-plugin' folder from the .zip in the folder with Indigo Plugins (/Library/Application Support/Perceptive Automation/Indigo/Plugins)
4. Rename the 'velux-indigo-plugin' folder as 'velux-indigo-plugin.indigoPlugin' (add the '.indigoPlugin' termination)
5. Run the installation script in the command terminal using chmod +x ./install.sh && ./install.sh
